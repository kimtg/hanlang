# 한랑 (韓浪) : 훈민정음 탈환기

> **"나랏말싸미 주먹에 실려, 저잣거리 악당들을 일망타진하노라!"**  
> 10월 9일 한글날을 맞이하여 고전 명작 액션 RPG 『열혈물어(열혈이야기)』 스타일을 계승한 **320 × 240 레트로 2.5D 벨트스크롤 액션 게임**입니다.

---

## 1. 게임 개요

| 항목 | 내용 |
| :--- | :--- |
| **게임 타이틀** | **한랑 (韓浪) : 훈민정음 탈환기** |
| **장르** | 2.5D 벨트스크롤 액션 RPG (Beat 'em up + RPG) |
| **개발 언어** | C# (.NET 10.0, Windows Forms 무의존성 픽셀 엔진) |
| **해상도** | **320 × 240** (가상 내부 버퍼) $\rightarrow$ 3배 정수 스케일링 **960 × 720** 창 출력 |
| **사운드** | 8비트 칩튠 멀티채널 사운드 신시사이저 (BGM 3곡 + 다양한 효과음) |
| **주요 특징** | 2등신 갓 쓴 SD 도트 캐릭터, CRT 스캔라인, 역경직(Hit-Stop) & 화면 흔들림, 대시 공격, 물체/적 들기 및 던지기, 주막 상점 경제 시스템, 보스 광폭화/슈퍼아머 레이드, 세이브/로드(JSON) |

## 2. 스토리

1446년(세종 28년), 세종대왕께서 백성들을 위해 친히 창제하신 훈민정음 해례본의 자모 비급이 의문의 '한자 마귀패'와 어둠의 학사단에게 탈취당했습니다!  
이에 격분한 집현전 최강의 무투파 의열 유생 **'한랑 (韓浪)'**이 두 주먹에 훈민정음의 기운을 담고 한양 저잣거리와 서당 골목, 광화문 앞마당을 누비며 악당들을 소탕하러 나섭니다!

## 3. 조작법 (Controls)

| 조작키 | 기능 | 상세 설명 |
| :--- | :--- | :--- |
| **방향키 (↑, ↓, ←, →)** | **2.5D 이동** | 상하(깊이 Y) 및 좌우(X) 이동 |
| **좌/우 2회 연속 입력** | **대시(달리기)** | 빠른 속도로 돌진 이동 |
| **대시 중 Z** | **대시 펀치** | 슬라이딩 정권 지르기 (다단 충격 및 히트스톱) |
| **대시 중 X** | **대시 킥** | 강력한 돌진 날아차기 (적 넉다운 및 화면 흔들림) |
| **Z** | **주먹 / 줍기 / 들고 때리기** | 맨손 3연타 / 바닥의 물체나 쓰러진 적 들기 / 든 채로 타격 |
| **X** | **발차기 / 던지기** | 적을 날리는 킥 / 들고 있는 물체나 쓰러진 적 전방 투척 |
| **C** | **점프** | 공중 도약 (점프 중 Z/X 입력 시 공중 날라차기) |
| **Space** | **한글 비기: 훈민선풍각** | 기력(MP 15)을 소모하는 화려한 회전 공격 (광채 이펙트) |
| **S** | **저잣거리 주막 / 보제원 상점** | 엽전(골드)으로 국밥/동동주/삼계탕 및 영약/비급서 구매 |
| **Tab / ESC** | **상태창 (성장 분배)** | 레벨업 시 획득한 스탯 포인트를 실시간 분배 |
| **F5** | **빠른 저장 (Quick Save)** | 현재 진행도, 레벨, 스탯을 `savegame.json`에 저장 |
| **F9** | **빠른 불러오기 (Quick Load)**| 저장된 데이터를 즉시 불러오기 |

## 4. 핵심 게임 시스템

### 4.1. 타격감 & 액션 시스템 (Action Juice)
- **역경직 (Hit-Stop)**: 강력한 공격 및 대시 공격 적중 시 찰나의 프레임 정지 연출로 묵직한 타격감 선사.
- **화면 흔들림 (Screen Shake)**: 강타 적중 시 화면이 흔들리는 박진감 넘치는 연출.
- **충격 스파크 & 먼지 파티클**: 타격 부위에서 튀는 섬광 파티클과 대시 마찰 먼지.
- **물체 및 적 들기 & 던지기**: 목봉, 궤짝, 돌멩이를 주워 휘두르거나 던질 수 있으며, 기절한 적을 머리 위로 들어 올려 적 무리에 내던질 수 있습니다. (적은 3초 후 몸부림치며 자동 탈출)
- **적 AI 원거리 투척**: 적들도 바닥의 물체를 주워 던지거나 원거리에서 돌멩이를 투척합니다.
- **데미지 플로팅 텍스트**: 피격당한 대상의 머리 위에 피해 숫자가 위로 떠오릅니다.

### 4.2. RPG 주막 & 보제원 경제 시스템
- 길바닥에 떨어진 엽전(골드)을 모아 언제든 `S` 키를 눌러 상점을 이용할 수 있습니다.
- **주막**: 장터국밥(체력 50 회복), 인절미와 동동주(HP/MP 완충), 수라상 삼계탕(완충 + 영구 힘 +2).
- **보제원 한약방**: 우황청심환(영구 맷집 +2), 용력환(영구 힘 +2), 천리마 환약(영구 날쌤 +2), 단전호흡 비급서(영구 기력 +2).

### 4.3. 보스전 대형 HUD & 광폭화(Rage) 레이드
- 보스 출현 시 화면 하단에 아케이드 스타일의 대형 체력 게이지와 칭호 배너가 표시됩니다.
- **보스 체력 50% 이하 광폭화**: 붉은 투기 오라를 발산하며 이동속도 1.3배 상승 및 **슈퍼아머(Super Armor)** 발동! 가벼운 공격의 피격 경직을 무시하고 돌진합니다.

### 4.4. 8비트 절차적 칩튠 BGM 사운드
- 타이틀 테마, 필드 스테이지 테마, 긴장감 넘치는 보스전 테마가 멀티채널(Square 멜로디 + Triangle 베이스 + Noise 리듬)로 무한 루프 재생됩니다.

### 4.5. 스테이지 구성 (전 9장 여정)
- **1장: 한양 저잣거리** (맑은 낮, 골목 깡패 소탕)
- **2장: 서당 뒷골목** (오후 노을, 불량 훈도와 깡패 연합)
- **3장: 청계천 다리** (석양의 돌다리, **중간보스: 괴력 건달 마달**)
- **4장: 남산 성곽길** (황혼의 성벽과 횃불, 암흑 결사대 난입)
- **5장: 도성 주막거리** (야간 주막 홍등, 야간 습격)
- **6장: 육조거리** (심야의 관아 앞, **중간보스: 무과 배신자 철웅**)
- **7장: 광화문 앞뜰** (먹구름 낀 성문, 정예 결사대 대공세)
- **8장: 경복궁 근정전** (붉은 핏빛 달밤, 궁궐 정예 결전)
- **9장: 집현전 천추전** (번개 치는 최종 결전, **최종 보스: 마도학사 흑호** 격퇴 후 훈민정음 어제 서문 엔딩)

## 5. 실행 방법

### 5.1. 게임 실행 (GUI 윈도우 창)
```bash
dotnet run
```
*실행 즉시 320×240 레트로 화면이 960×720의 선명한 3배 정수 스케일링 창으로 표시되며 8비트 BGM이 흐릅니다.*

### 5.2. 자동화 무결성 테스트 실행
```bash
dotnet run -- --test
```
*스탯 계산, 2.5D 충돌, 대시 공격, 역경직/화면 흔들림, 상점 구매, 보스 슈퍼아머, 적 투척, 9개 장 구성, 세이브/로드 등 112개 핵심 시스템 단위 테스트가 100% 통과되는지 검증합니다.*
